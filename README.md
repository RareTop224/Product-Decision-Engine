# Product Decision Engine

Исследовательский прототип Phase 0 для проверки гипотезы: может ли выбор
принтера по подтверждённой полной стоимости владения быть полезнее простой
сортировки по цене покупки.

Сейчас проект намеренно не содержит web-интерфейса, API, авторизации и
production-сборщиков данных. Факты хранятся в Golden Dataset вместе с
evidence, а фильтрация и денежные расчёты выполняются детерминированным кодом.

## Локальный запуск

Проект использует Python 3.11+ и на текущем этапе не требует runtime-зависимостей.

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python scripts/evaluate_phase0.py
```

Evaluation-команда читает JSON из `data/golden`, записывает воспроизводимый
отчёт в `reports/generated/phase0-report.md` и не изменяет исходный dataset.

## Текущий статус

Первый рабочий срез фиксирует предметную модель, hard constraints, TCO-математику,
валидацию evidence и формат данных. Промежуточный Golden Dataset содержит 12
реальных моделей пяти брендов и 15 сценариев. Расширение до 30–50 моделей и
окончательный вывод `GO`, `REASSESS` или `NO-GO` ещё не завершены.
