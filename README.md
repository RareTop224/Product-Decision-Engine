# Product Decision Engine

Исследовательский прототип Phase 0 для проверки гипотезы: может ли выбор
принтера по подтверждённой полной стоимости владения быть полезнее простой
сортировки по цене покупки.

Сейчас проект намеренно не содержит web-интерфейса, API, авторизации и
production-сборщиков данных. Факты хранятся в Golden Dataset вместе с
evidence, а фильтрация и денежные расчёты выполняются детерминированным кодом.

## Локальный запуск

Проект использует Python 3.11+ и на текущем этапе не требует runtime-зависимостей.

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python scripts/evaluate_phase0.py
```

Evaluation-команда читает JSON из `data/golden`, записывает воспроизводимый
отчёт в `reports/generated/phase0-report.md` и не изменяет исходный dataset.

## Текущий статус

Рабочий срез фиксирует предметную модель, hard constraints, TCO-математику,
валидацию evidence, диапазоны наблюдаемых цен и формат данных. Golden Dataset
содержит 30 реальных моделей семи брендов и 15 сценариев. Минимальный объём
выборки достигнут; воспроизводимый отчёт сейчас даёт вывод `REASSESS`, потому
что экономический эффект заметен, но контроль чувствительности после расширения
сводится к одному победителю. Дополнительная проверка единственной смены
относительно упрощённого TCO показала отрыв 461 ₽ из-за starter-комплекта, но не
нашла полной синхронной корзины для пары HP Smart Tank 720 и Epson L4260 ни у
одного из трёх проверенных продавцов. Отдельная контрольная пара Canon PIXMA
TS3640 ↔ HP DeskJet Ink Advantage 2875 подтверждена полными корзинами у KNS и
Regard: при более низкой цене покупки Canon полный TCO выбирает HP с экономией
9 676–11 790 ₽ на сценарии 40 ч/б + 10 цветных страниц в месяц за пять лет.
Это подтверждает экономический сигнал у двух продавцов, но пока не снимает
общий статус `REASSESS`: широкая рыночная и сценарная устойчивость ещё не
доказана.
